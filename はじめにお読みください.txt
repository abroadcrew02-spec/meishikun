名刺抽出ツール（meishi_extractor）の使い方

■ できること
  名刺をスキャンした PDF（AI-OCR 済み・文字情報つき）から、会社名・氏名・役職・
  郵便番号・住所・電話・FAX・メール・URL を読み取り、Excel と CSV の一覧表にします。
  一覧表を作る前に、「どこからどこまでが 1 枚の名刺か」を画面で確かめて直せます。

■ 初めて使う PC での準備（1 回だけ）
  ・フォルダに「runtime」がある場合 → 準備は要りません。そのまま使えます。
  ・「runtime」が無い場合 → 「初めて使う方はこちら.bat」をダブルクリックしてください。
      インターネットから Python と必要な部品を取ってきて「runtime」フォルダを作ります
      （数分かかります。Python を PC にインストールする必要はありません）。
      最後に「準備完了」と出れば終わりです。

■ 使い方（4 ステップ）
  1. 名刺の PDF を「input」フォルダに入れる（複数まとめて入れても大丈夫です）
  2. 「run.bat」をダブルクリックする
     （黒い画面が開いて PDF を読み込み、終わるとブラウザに確認画面が開きます）
  3. 確認画面で、名刺を囲む赤い枠を確かめる。ずれていれば直して「出力する」を押す
  4. 「output」フォルダの中にできた、PDF と同じ名前のフォルダを開く

  黒い画面は、出力が終わるまで閉じないでください。閉じると中止になります。

■ 確認画面の使い方
  ・左に PDF とページの一覧、中央にページの画像、右にそのページの枠の一覧が出ます。
  ・赤い枠 1 つが名刺 1 枚です。枠に付いた記号（A, B, C…）が一覧表の「ラベル」になります。
  ・茶色の点線と「!」の枠は、ツールが迷った枠です（2 枚がくっついている疑い など）。
    右の一覧に理由が出ます。
  ・青い点線は、どの枠にも入っていない文字です。そのまま出力すると一覧表に入りません。
    名刺の文字なら、枠を広げるか「枠を追加」で囲んでください。
  ・枠の直し方
      動かす           枠の中をドラッグ
      大きさを変える   枠を選んで、角や辺の四角いつまみをドラッグ
      足す             「枠を追加」を押して、名刺をドラッグして囲む
      消す             枠を選んで「この枠を削除」
      2 枚に分ける     枠を選んで「左右に分ける」「上下に分ける」
      やり直す         「元に戻す」（Ctrl+Z）。ページごと最初に戻すなら「自動の枠に戻す」
    キーボードだけでも操作できます（画面右の「キーボードでの操作」を開くと一覧が出ます）。
  ・1 か所でも枠を直したページは、枠の内側（と枠から 3mm 以内）の文字だけを読みます。
    直す前は枠の外の文字を近くの名刺に足していたページでも、直した後は足しません。
  ・直した内容は自動で保存されます。ブラウザを閉じてしまっても、黒い画面に出ている
    アドレスを開けば続きから作業できます。ただし「元に戻す」で戻れるのは、画面を
    開いている間の操作だけです（再読み込みや開き直しの前の操作には戻れません）。
  ・ブラウザの表示を拡大すると（Ctrl と +）、一覧・画像・操作の欄が縦に並びます。
  ・ブラウザを閉じただけでは終わりません。終える時は「出力する」か「中止する」を押します。
    「中止する」を押すと何も出力されず、PDF は input フォルダに残ります。
  ・確認している間は、input フォルダの PDF を動かしたり入れ替えたりしないでください。
    変わっていた PDF は出力せず、input フォルダに残します。

■ 確認画面を使わずに一括で出力する
  「run_auto.bat」をダブルクリックすると、枠の確認をせずに、ツールが決めた枠のまま
  出力します（これまでの run.bat と同じ動きです）。

■ フォルダとファイルの説明
  input\         処理したい PDF を入れる場所
  output\        結果。PDF ごとに同じ名前のフォルダができ、その中に次の 3 つが入ります
                   <PDF 名>.xlsx        一覧表（Excel）
                   <PDF 名>.csv         一覧表（CSV。Excel でも開けます）
                   <PDF 名>_split.pdf   分割確認用。赤い枠が「1 枚の名刺」として読んだ範囲
  done\          処理が終わった PDF が input から移動してきます（元の PDF は消しません）
  error\         処理できなかった PDF（文字情報が無い・PDF として開けない など）
  logs\          実行の記録。名刺の中身は書いていません。うまくいかない時に見ます
  dict\          読み取りに使う辞書（役職・会社の種類・拠点の語・電話の見出し など）。足りない
                 言葉は足せます（下の「読み取りの辞書」）
  app\           プログラム本体。触りません
  dev\           開発者向け（設計書・テスト）。触りません
  worklog\       開発作業の記録（開発者向け）。触りません
  config.ini     設定ファイル。出力形式や判定の細かい値。普段は触りません
  初めて使う方はこちら.bat  runtime が無い時に 1 回だけ実行する準備用
  runtime\       このツール専用の Python と部品（約 80MB）。触りません。消しても
                 「初めて使う方はこちら.bat」で作り直せます
  requirements.txt  準備で入れる部品の一覧。触りません
  run.bat        実行用（ダブルクリック）。確認画面で枠を確かめてから出力します
  run_auto.bat   実行用（ダブルクリック）。確認画面を使わずに出力します
  dict.bat       辞書の画面を開きます。読み取りに使う言葉を、画面で足せます
  clear.bat      output の中身（一覧表・分割確認 PDF）を全部消します。消す前に件数を
                 表示して確認します（y で実行）。logs・done・error・input は残ります
  diagnose.bat   うまく読めない時の診断用。input の PDF を動かさずに中身を調べます

■ 一覧表の見方
  ・1 行が名刺 1 枚です。「ページ」と「ラベル」は、確認画面と分割確認 PDF の枠に
    書かれた記号（A, B, C…）と対応しています。
  ・「要確認」列に 1 が付いた行は、読み取りに迷いがあった名刺です。理由は
    「要確認理由」列にあります。元の名刺と見比べてください。
  ・どの項目か分からなかった言葉は「未分類」列に入ります。
  ・電話番号は、名刺に印字された区切り（ハイフン）のまま出します。
  ・郵便番号は「100-0001」の形で、住所とは別の列に入ります。〒が「T」や「+」と読まれていても拾います。
  ・部署（○○部・○○課・○○室 など）は「部署」列に入ります。「営業部 部長」のような行は
    部署=営業部、役職=部長 に分かれます。
  ・役職は dict\titles.txt の語で判定します。足りない語があれば 1 行 1 語で足せます
    （「〜長」で終わる語は辞書に無くても役職として拾います）。

■ 読み取りの辞書（dict フォルダ）
  読み取りに使う言葉は、dict フォルダのファイルに 1 行 1 語で入っています。足りない言葉は、
  辞書の画面（dict.bat）か、メモ帳で足せます。足した言葉は、次の実行から使われます。

  辞書の画面の使い方:
    1. dict.bat をダブルクリックします。ブラウザで辞書の画面が開きます。
    2. 左で辞書の種類を選び、言葉を入れて「追加」を押します。入れられない言葉は、理由が出ます。
    3. 「試し読み」を押すと、done と input の PDF（新しい順に 30 本まで）を、今の辞書と変更後の辞書の
       両方で読み比べて、結果が変わる名刺の枚数を出します。PDF は動かしません。
    4. 「保存する」を押すと、辞書ファイルが書き換わります。保存するまでは変わりません。
    5. 「終わる」を押します。ブラウザを閉じただけでは終わりません。
  ・試し読みで結果が変わった時は、どの名刺のどの項目がどう変わるかを、output フォルダの
    「辞書の試し読み_…」の中の 比較.xlsx に書きます。比較表には名刺の内容が入ります。
    確かめたら、clear.bat で消してください。
  ・辞書の画面を開いている間は、名刺の読み取り（run.bat・run_auto.bat）を実行できません。
    操作が無いまま 1 時間たつと、保存していない変更が無ければ、辞書の画面は自動で終わります。
  ・辞書のファイルをほかのソフト（Excel など）で開いたままだと、保存できません。そのソフトを閉じてから、
    もう一度「保存する」を押してください。
  ・保存の途中で黒い画面を閉じたり、電源が切れたりした時は、次に実行した時に、保存する前の辞書へ戻します。
  ・保存のたびに、書き換える前の辞書が dict\backup フォルダに残ります（辞書ごとに新しい 10 件）。
    元に戻したい時は、控えのファイルの中身を、メモ帳で元のファイルに写してください。
    要らない控えは、消してかまいません。
  ・辞書の画面も、この PC の中だけで動きます。インターネットには接続しません。
  ・辞書ファイルを、Windows のアクセス権で書き込み禁止にしていても、保存で置き換わることがあります。
    書き換えさせたくない時は、ファイルを「読み取り専用」にしてください（その時は、保存を断ります）。

  メモ帳で足す時は、ファイルを開いて 1 行に 1 語ずつ書きます（# で始まる行は説明です）。

    こんな時                                          足すファイル
    会社名が「未分類」に入る（○○弁護士法人 など）     corp_suffixes.txt  会社の種類（「弁護士法人」を足す）
    役職が「未分類」に入る                            titles.txt         役職
    部署が「氏名」や「未分類」に入る                  dept_suffixes.txt  部署の語尾（「部」「課」など）
    住所の前の拠点名が「未分類」に入る（出張所 など） branch_labels.txt  拠点の語
    会社でない組織の名前が「氏名」に入る（○○技研 など） org_suffixes.txt  組織名の語尾（「技研」を足す）
    見出しつきの電話番号が読まれない（ダイヤルイン など） tel_prefixes.txt  電話の見出し
    FAX の番号が「電話」に入る（ファクシミリ など）   fax_prefixes.txt   FAX の見出し

  ・足すのは「語尾」や「見出し」だけにしてください。会社名・氏名・電話番号など、名刺の内容そのものは
    書かないでください（辞書は、名刺の内容を置く場所として扱っていません）。
  ・短い言葉（1〜2 文字）を足すと、関係のない言葉まで拾うことがあります。足した後は、いくつかの PDF で
    結果を確かめてください。
  ・branch_labels.txt・org_suffixes.txt・tel_prefixes.txt・fax_prefixes.txt は、消すか、言葉を 1 つも
    書かないと、最初から入っている言葉で動きます。titles.txt と corp_suffixes.txt は空にできません。
  ・old_kanji.csv（旧字体）と area_codes.csv（市外局番）は、Excel で開いて保存すると形が崩れることが
    あります。メモ帳で開いてください。

■ うまくいかない時
  ・確認画面が開かない
      → 黒い画面に出ているアドレス（http://127.0.0.1: で始まる行）を、Edge か Chrome の
        アドレス欄に貼り付けて開いてください。それでも開かない時は run_auto.bat を使うか、
        開発者に相談してください。
  ・「別の実行…が動いているか、logs フォルダの meishi.lock を開けません」と出る
      → 前に開いた黒い画面が残っています。確認画面なら「出力する」か「中止する」を、
        辞書の画面なら「終わる」を押すか、残っている黒い画面を閉じてから、
        もう一度実行してください。
        黒い画面が残っていないのに出る時は、logs フォルダの meishi.lock を消してから
        実行してください（中身の無いファイルで、次の実行の時に作り直されます）。
  ・「処理不可」と出て error フォルダに移った（確認画面では「読めません」と出る）
      → その PDF に文字情報が無い（画像だけ）か、PDF として開けません。
        スキャナーの OCR（文字認識）の設定を確認してください。
  ・赤い枠が名刺とずれている
      → 確認画面で枠を直してください。何度も同じずれ方をする時は、名刺どうしの間隔を
        1cm 以上空け、まっすぐ置いて再スキャンすると、最初から合いやすくなります。
        細かい調整は config.ini の [split] の値で行います（開発者に相談してください）。
  ・同じ名前の PDF をもう一度処理した
      → output には「<PDF 名>_2」のように番号付きのフォルダができます。
        前の結果は上書きしません。
  ・黒い画面に「Python was not found」「PyMuPDF / openpyxl が見つかりません」と出る
      → 「初めて使う方はこちら.bat」を実行してください。
  ・「初めて使う方はこちら.bat」で「準備に失敗しました」と出る
      → インターネット接続（会社のプロキシ）が原因のことが多いです。開発者に相談するか、
        runtime 入りのフォルダを受け取ってください。

■ 注意
  ・このツールはインターネットに接続しません。名刺の情報は、ツールからこの PC の外へは
    出ません。確認画面と辞書の画面は、この PC の中だけでツールとブラウザがやり取りして表示します
    （他の PC からは開けません）。ブラウザ自体の通信（更新や同期など）は普段どおりです。
  ・確認画面には名刺の画像が出ます。この画面では、ブラウザの画像検索・翻訳・AI の
    サイドバーなど、表示中のページを外部へ送る機能を使わないでください。ブラウザの
    拡張機能も、表示中のページを読むことがあります。
  ・黒い画面に出るアドレス（http://127.0.0.1: で始まる行）は、他の人に教えたり、チャットや
    メールに貼ったりしないでください。1 台の PC を複数の人が同時に使う環境では、アドレスを
    知っている人が確認画面や辞書の画面を開けます（辞書の画面では、言葉を足して保存できます）。
  ・確認画面や辞書の画面を開いたまま席を離れる時は、PC をロックしてください。
  ・output と done には名刺の個人情報が入ります。取り扱いにご注意ください。
  ・このツールのフォルダを、OneDrive などの同期されるフォルダ（同期の対象になっているデスクトップを含む）に
    置くと、一覧表・比較表・辞書の控え（dict\backup）も、同期の仕組みでこの PC の外へ送られます。
